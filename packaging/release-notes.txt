## Private GitHub device sync

- Add a GitHub Sync tab under Devices and Accounts for computers outside the same LAN, including device C.
- Upload whitelisted hourly token/model/cache summaries and quota/reset snapshots to each device's directory in a private repository.
- Refuse public repositories. Never upload conversations, task names, local paths, raw account IDs or Codex/DSH credentials.
- Protect optional GitHub credentials per Windows user; never include them in the updater or share them with another computer.
- Retain stale counts and mark offline devices. Never add shared account quota percentages or represent missing activity as zero.
- Sync every five minutes, batch recent history, skip unchanged files and retry one conflicting file update.
- Preserve the existing recorder, legacy A/B routing, databases, pause state, pairing, themes and widget settings.

Existing users: use Check and Update, then Devices and Accounts -> GitHub Sync. Initial private repository access must be configured separately on each computer.
Validation covers private-only writes, privacy filtering, offline records, read-only mode, idempotence, failed-upload recovery, credential protection and upgrade compatibility.
