## Layout and transparency fixes

- Fix live redraw artifacts in the display switches and transparency slider. Repeated setting changes no longer replay text or slider graphics in other controls.
- Defer dashboard and preferences DPI scaling until their controls have been created. Restore consistent spacing at 125% scaling and separate the large quota number from its usage caption.
- When Windows transparency effects are disabled, use real per-pixel alpha transparency instead of displaying an opaque black blur window. Text stays opaque; system preferences remain unchanged.
- Retain UTF-8 update decoding, ASCII release metadata for old-updater compatibility, records, pairing, account paths, pause and reminder settings.

Existing users: use Check and Update. Manual installation: download and run UsageObserver-Setup.exe.
Validation covers native 125% redraw, actual background pixels at 78% transparency, focus preservation and isolated upgrade retention.
