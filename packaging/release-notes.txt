## OpenAI status and output speed

- Monitor official Codex and ChatGPT Work components every 60 seconds without blocking the UI.
- Show service health and approximate local output tokens/second in every widget size.
- Refresh the 30-minute per-response effective rate every 15 seconds. Include reasoning and model-phase waiting; exclude explicit tool execution. This is not pure decode TPS.
- Retain stale values on failure; show unknown or pending when evidence is missing. Never treat failed status checks as normal or missing speed as zero.
- Provide scoped incident links, coverage details and optional deduplicated degradation/recovery notifications.
- Read existing response metadata and SQLite databases without writes. No inference requests or account data sent to the status service.
- Preserve records, recorder continuity, pairing, pause state, themes, widget dimensions and transparency.
- Keep UTF-8 update parsing and ASCII release metadata for old-client compatibility.

Existing users: use Check and Update. Manual installation: run UsageObserver-Setup.exe.

Includes the existing private GitHub device sync feature from 1.0.4.12.
