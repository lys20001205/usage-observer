# UsageObserver

1.0.4.7 修复程序更新：GitHub 发布信息显式按 UTF-8 解码，避免中文标题被 Windows 默认编码误读后出现 JSON (1522) 错误。正式 Release 的标题和说明保留 ASCII，兼容尚未修复的 1.0.4.x 更新器；其他机器仍可通过原来的“检查并更新”安装修复，无需先修改各自程序。中文使用说明继续保留在本 README。完整安装包沿用 1.0.4.6 的界面、记录和设置保留逻辑。

1.0.4.6 界面改版：采用暖灰底色、墨绿主卡和柔和薄荷色，统一总览、显示设置、设备、更新和重置公告页。总览突出额度与余额，减少说明文字干扰；设置采用分组卡片、开关和连续透明度滑杆，键盘可用方向键 / Page Up、Down / Home、End 调整，向辅助功能暴露百分比。按钮增加悬停、按下与键盘焦点状态，常用操作和次要工具区分层级。

浮窗右键 → 背景透明度可选常用档位，“自定义透明度”或面板的“显示与提醒”提供 0–90% 滑杆，即时生效并自动保存。只调整背景透明度，文字保持不透明。移除浅色外描边与常驻缩放纹；小浮窗保留 Codex 额度、DSH 余额和一行北京时间，省去正常记录状态和重复更新时间。文字按可用宽度完整绘制，不生成省略号；大余额使用 K/M 等短单位，悬停和详情保留完整数据。预告、社区预计、最晚时间和旧预告仍明确区分。

背景使用原生圆角裁剪，半透明渐变与文字层分开绘制。实机合成检查覆盖透明度档位变化、背景色变化、背景条纹模糊、圆角外无残留和前台焦点保持。浮窗默认 160×92，可拖动任意边缘或右下角缩放，144×88 至 560×360 的逻辑尺寸随 DPI 调整。拖中间移动，尺寸自动保存；小尺寸精简、拉宽并排、拉高增加 token。文字采用原生每屏 DPI 绘制。总览采用 620×736 布局，矮屏支持滚动，设备、设置、更新页面共用配色与按钮样式。

`src/` 包含从已安装 1.0.4.1 程序恢复的 Windows Forms UI 源码及本次改动。运行 `src/build-ui.ps1` 编译；使用隔离的 `USAGE_OBSERVER_DATA` 目录执行 `UsageObserver.exe --self-test <预览路径.png>` 可生成无焦点的测试预览。本仓库中的 UI 源码依赖现有安装包的采集后端与运行时，不包含用户数据。

`UsageObserver.exe --composition-test <输出目录>` 使用生成的测试背景进行短暂、无激活的实机合成检查。验证读取测试图案范围的屏幕像素，不注入鼠标/键盘输入。透明与模糊必须通过像素对照，不能仅凭原生接口返回成功判定。背景模糊使用兼容性合成接口，后续 Windows 更新可能影响其行为；不支持时回退到半透明配色。

Windows 10/11 x64 的 Codex 与 DeepSeek DSH 用量浮窗。第三方本地工具。

- 显示本机 Codex 账号额度、服务器返回的重置时间和日志 token。
- 1.0.4.1 包含重置预告时间、新版总览/详情设计、浮窗恢复及预告提醒：每小时检查公开消息，有新消息才通知，重启不重复提醒。
- 显示 DSH 当前登录账户的余额、今日 token 和自定义提醒。
- 可拖动浮窗、悬停详情、任务栏图标和按用户设置开机启动。
- 同一专用局域网内发现设备，配对后加密交换用量摘要。
- 公开 GitHub Releases 提供联网电脑的一键程序更新。

程序读取每台电脑已有的登录，不登录、退出或复制账户凭据；不创建模型任务。同一账号额度/余额是共享快照，不相加。日志 token 表示所选目录的本机记录，不能换算某台机器消耗的账号额度百分点。

安装包见 [Releases](https://github.com/lys20001205/usage-observer/releases)。首次安装后，浮窗右键 → 检查程序更新 → 检查并更新。新版默认使用本仓库，无需手填地址。此功能需要目标电脑可以访问 GitHub。

更新保留本机数据库、记录起点、路径设置、提醒、手动暂停、开机启动和配对信息。下载校验 GitHub 提供的 SHA-256 与大小；安装前检查内置 manifest，替换失败尝试恢复旧文件。程序文件和数据目录分离：

- 程序：`%LOCALAPPDATA%\Programs\UsageObserver`
- 数据：`%LOCALAPPDATA%\UsageObserver`

局域网汇总需要在每台电脑安装并运行，同组配对；它不提供跨外网用量汇总，也不能追溯未安装设备的历史使用。DSH 监控当前 deepseek-account 登录，不包括其他 API Key 客户端的调用。余额净变化不是逐笔账单。

安装包包含运行时和第三方许可文件，不包含开发电脑的账户、用量记录、配对码、日志或审计材料。Windows 程序尚未做代码签名。新版本先在隔离安装目录验证升级、保留配置和回滚；无法保证所有账户或供应商版本兼容。

全局预告来源为 [When Next Reset](https://whennextreset.com/zh) 的独立社区接口，并用 X 官方 oEmbed 核对原帖作者与正文。社区预计时间不当作官方精确时间，到点不自动确认重置；公共公告不证明个人账号已到账。重置卡和普通周期重置不触发此提醒；无需提供 API Key，不发送账户或用量给公告来源。

1.0.4.1 的浮窗显示预告北京时间；高置信仅用于已核对原帖的明确日期、时间和时区，模糊 EOD 与社区预计不会获得此标签。设置集中在“提醒与显示”。

1.0.4.1 补齐“开始传播”与后续完成公告的详情衔接，始终显示较新的公告；浮窗预告显式标注北京时间。

## 发布构建

运行 `packaging/build-release.ps1 -OutputDirectory <输出目录>` 生成完整的 `UsageObserver-Setup.exe` 和 `UsageObserver-Windows-x64.zip`。构建从 SHA-256 固定的 v1.0.4.1 安装包获取原采集后端及许可证/运行时，逐文件验证，再编译当前界面与安装器。用户记录和设置不进入构建。安装脚本保留原文件校验、备份与回滚流程；支持隔离验证、普通安装及现有 UpdateHelper 的自动更新协议。

远端“检查更新”只读取最新正式 GitHub Release 的 `UsageObserver-Setup.exe` 附件，不读取 main 分支的源码提交。发布必须包含该完整安装附件。
